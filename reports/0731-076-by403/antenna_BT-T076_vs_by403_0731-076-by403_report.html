18. StdDev-ADR 与 C/N0 联合散点对比

按频点着色、按天线形状区分展示干扰段内 StdDev-ADR 与 C/N0 的关系。若某频点在干扰下 C/N0 下降且 StdDev-ADR 上升，说明该频段受干扰影响显著。

19. 综合结论

基于 0731-076-by403 真实同步测试数据（COM3 TRACKSTAT C/No）的对比结论：

1. 整体水平：两根天线整体 C/N0 中位数、PLL 锁定率、跟踪星数、参与解算星数均非常接近，北天BT-T076 与 by403 无显著整体优劣。 2. 相关性：按卫星平均后的 Fisher-z 平均 r = 0.492（中等相关），逐星 r 中位数 = 0.494；总体样本 r = 0.674。两根天线对同一电磁环境的响应具有一定一致性，但不同卫星间相关程度差异较大。 3. 显著性检验：Wilcoxon 符号秩检验显示 2 个片段 北天BT-T076 显著更高、0 个片段 by403 显著更高、7 个片段无显著差异。 4. 抗干扰性（干扰段平均 ΔC/N0）：北天BT-T076 平均衰减 -3.14 dB；by403 平均衰减 -4.73 dB（越接近 0 表示抗干扰越强，详见第 9 章逐场景对比）。 5. 卫星保持：干扰段累计丢失卫星数 北天BT-T076 为 0 颗次，by403 为 4 颗次。 6. 分场景退化：392MHz 干扰 场景 北天BT-T076 更稳健（ΔC/N0 -8.94 dB vs -11.38 dB）；409MHz 干扰 场景 北天BT-T076 更稳健（ΔC/N0 -3.56 dB vs -7.31 dB）；4G/5G 干扰 场景 两者基本持平；Wi-Fi 干扰 场景 两者基本持平。 7. 绝对接收能力：基线（无干扰）C/N0 差值中位数 = 0.00 dB（两者持平 基线更高）；干扰段 C/N0 差值中位数 = 1.38 dB（北天BT-T076 干扰段绝对水平更高）。 8. 相对抗干扰能力：392MHz 干扰 北天BT-T076 退化更小；409MHz 干扰 北天BT-T076 退化更小；4G/5G 干扰 退化相当；Wi-Fi 干扰 退化相当。 9. 总体性能判定：两者整体性能接近，无显著优劣。

说明：COM4 二进制 北天BT-T076/by403 中，北天BT-T076 为标准 RANGECMP（ID 140）；by403 为标准 RANGECMP（ID 140）；结论为“天线 + M21 内置抗干扰算法”的系统级结论。
