5.1 伪距退化指标说明（GPGST 替代 RANGECMPB）

COM4 二进制流经检查仅包含消息 ID 0xA521（42273），并非 UG016/OEM7 文档中定义的 RANGECMPB（消息 ID 140，0x008C），因此无法输出逐星逐频点的伪距标准差。

作为替代，本报告采用 COM3 ASCII 的 $GPGST 字段 3——“用于导航计算的伪距标准偏差 RMS（m）”。该字段与 M21 方案中“伪距退化”判定维度直接对应：

  • RANGECMPB：通道级、逐星逐频点伪距标准差，可精确定位受干扰频点；
  • GPGST 字段 3：解算层/整体级伪距 RMS，反映所有参与解算卫星的伪距综合质量。

因此，在 COM4 不可用时，GPGST 字段 3 可以承担“伪距退化”评估职能，但不能提供单颗卫星的伪距质量细节。上表中的“伪距 RMS”即取自该字段。

本文件统计：GPGST 字段 3 中位数 = 0.030 m；最小值 = 0.020 m；最大值 = 0.030 m。

8. 结论与说明

  • 本报告完全基于 COM3 ASCII 数据；COM4 二进制因消息 ID 与 UG016 RANGECMPB 不符而未使用。
  • 干扰段判定基于“文件中间 30 s”这一结构假设，未使用外部触发或功率监测。
  • C/N0、锁定状态、失锁、定位类型等核心指标均来自 UG016 定义的 TRACKSTAT/BESTPOS/GST/GSV。
