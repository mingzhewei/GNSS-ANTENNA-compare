4. COM4 二进制一致性与 GPGST 替代说明

两个 COM4 文件均为消息 ID 0xA521（42273）的自定义二进制消息，不是 UG016/OEM7 定义的 RANGECMPB（ID 140），因此无法按方案原设计输出逐星伪距标准差。

作为替代，本对比采用 COM3 ASCII 的 $GPGST 字段 3（伪距 RMS，m）来评估“伪距退化”这一判定维度。GPGST 字段 3 是解算层/整体级指标，可以反映干扰是否导致伪距精度整体下降，但不具备 RANGECMPB 的逐星分辨能力。因此，当前“伪距 RMS”列仅用于定位级退化判断，不能替代通道级分析。

上表“伪距 RMS”为各时段 GPGST 字段 3 的中位数。111 基线/干扰/恢复三段数值分别为 0.030 / 0.030 / 0.030 m；222 分别为 0.030 / 0.030 / 0.030 m。
