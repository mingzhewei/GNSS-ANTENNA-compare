6. 逐星 C/N0 相关性分析

对两颗天线均观测到的每颗卫星，先把同一历元多频点通道的 C/N0 聚合为单值（取中位数），再按同一 GPS 周内秒（sow）一一配对计算 Pearson 相关系数 r，故配对样本数即共同历元数。由于不同卫星 C/N0 基线不同，合并所有样本得到的总体 r 会受卫星构成影响；因此同时给出 Fisher-z 变换后的平均 r（跨卫星平均）以及逐星 r 的中位数/分布。r ≥ 0.7 为强相关，0.4–0.7 为中等相关，< 0.4 为弱相关。

18. 综合结论

基于 0731-076-speed 真实同步测试数据（COM3 TRACKSTAT C/No）的对比结论：

1. 整体水平：北天BT-T076 整体 C/N0 中位数更高（44.75 dB-Hz vs speed 43.25 dB-Hz，高 1.50 dB）；PLL 锁定率、跟踪星数、参与解算星数等整体指标详见第 2 章。 2. 相关性：按卫星平均后的 Fisher-z 平均 r = 0.777（强相关），逐星 r 中位数 = 0.786；总体样本 r = 0.876。两根天线对同一电磁环境的响应具有一定一致性，但不同卫星间相关程度差异较大。 3. 显著性检验：Wilcoxon 符号秩检验显示 8 个片段 北天BT-T076 显著更高、0 个片段 speed 显著更高、1 个片段无显著差异。 4. 抗干扰性（干扰段平均 ΔC/N0）：北天BT-T076 平均衰减 -2.66 dB；speed 平均衰减 -2.19 dB（越接近 0 表示抗干扰越强，详见第 9 章逐场景对比）。 5. 卫星保持：干扰段累计丢失卫星数 北天BT-T076 为 2 颗次，speed 为 3 颗次。 6. 分场景退化：392MHz 干扰 场景 speed 更稳健（ΔC/N0 -6.25 dB vs -7.38 dB）；409MHz 干扰 场景 speed 更稳健（ΔC/N0 -2.25 dB vs -3.25 dB）；4G/5G 干扰 场景 两者基本持平；Wi-Fi 干扰 场景 两者基本持平。 7. 绝对接收能力：基线（无干扰）C/N0 差值中位数 = 1.50 dB（北天BT-T076 基线更高）；干扰段 C/N0 差值中位数 = 1.12 dB（北天BT-T076 干扰段绝对水平更高）。 8. 相对抗干扰能力：392MHz 干扰 speed 退化更小；409MHz 干扰 speed 退化更小；4G/5G 干扰 退化相当；Wi-Fi 干扰 退化相当。 9. 总体性能判定：北天BT-T076 整体性能更强：基线更高且干扰段绝对水平仍保持领先。

说明：COM4 二进制 北天BT-T076/speed 中，北天BT-T076 为标准 RANGECMP（ID 140）；speed 为标准 RANGECMP（ID 140）；结论为“天线 + M21 内置抗干扰算法”的系统级结论。
