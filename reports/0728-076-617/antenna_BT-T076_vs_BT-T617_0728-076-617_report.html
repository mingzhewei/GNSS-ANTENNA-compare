17. StdDev-ADR 与 C/N0 联合散点对比

按频点着色、按天线形状区分展示干扰段内 StdDev-ADR 与 C/N0 的关系。若某频点在干扰下 C/N0 下降且 StdDev-ADR 上升，说明该频段受干扰影响显著。

18. 综合结论

基于 0728-076-617 真实同步测试数据（COM3 TRACKSTAT C/No）的对比结论：

1. 整体水平：两根天线整体 C/N0 中位数、PLL 锁定率、跟踪星数、参与解算星数均非常接近，北天BT-T076 与 北天BT-T617 无显著整体优劣。 2. 相关性：按卫星平均后的 Fisher-z 平均 r = 0.436（中等相关），逐星 r 中位数 = 0.348；总体样本 r = 0.749。两根天线对同一电磁环境的响应具有一定一致性，但不同卫星间相关程度差异较大。 3. 显著性检验：Wilcoxon 符号秩检验显示 0 个片段 北天BT-T076 显著更高、8 个片段 北天BT-T617 显著更高、1 个片段无显著差异。 4. 抗干扰性（参考 ETSI EN 303 413 的 1 dB 行业参考线）：北天BT-T076 在 4 种干扰中通过 2 种；北天BT-T617 通过 3 种。 5. 卫星保持：干扰段累计丢失卫星数 北天BT-T076 为 3 颗次，北天BT-T617 为 7 颗次。 6. 分场景：392MHz 干扰 场景 北天BT-T076 更稳健（ΔC/N0 -5.75 dB vs -6.88 dB）；409MHz 干扰 场景 北天BT-T617 更稳健（ΔC/N0 -0.88 dB vs -2.56 dB）；4G/5G 干扰 场景 两者基本持平；Wi-Fi 干扰 场景 两者基本持平。

说明：COM4 二进制 北天BT-T076/北天BT-T617 中，北天BT-T076 为标准 RANGECMP（ID 140）；北天BT-T617 为标准 RANGECMP（ID 140）；结论为“天线 + M21 内置抗干扰算法”的系统级结论。
